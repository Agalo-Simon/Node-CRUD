# Node-CRUD Application

A lightweight, server-side Model-View-Controller (MVC) CRUD web application built with Node.js, Express, and MongoDB. This project provides a foundational boilerplate for handling API routing, server-side HTML rendering, and database persistence.

---

## 🚀 Features

*   **RESTful Routing:** Dedicated API endpoints for standard CRUD handling under `/api/items`.
*   **Database Integration:** Object data modeling via Mongoose, pre-configured for MongoDB Atlas.
*   **Dynamic Templating:** Server-side view rendering using EJS (Embedded JavaScript templates).
*   **Request Logging:** Real-time HTTP request logging utilizing `morgan` for easier debugging.
*   **Static Assets:** Built-in middleware configured to serve CSS, images, and client-side JS from a public directory.

---

## 🛠️ Tech Stack

*   **Runtime Environment:** Node.js
*   **Framework:** Express.js
*   **Database:** MongoDB Atlas (via Mongoose)
*   **View Engine:** EJS
*   **Development Tools:** Nodemon (auto-restarting development server), Morgan (HTTP logger)
